# Pipeline Column Dictionary & Data Schema Reference

**Last Updated**: 2026-08-07  
**Pipeline Build**: GRCh38 Annotation Pipeline v2.0  

This document provides a comprehensive specification of all standard output columns generated by the pipeline, with special emphasis on newly added fields, refactored column names, and unified status contracts (`scored`, `not_covered`, `error`).

## 2. Complete Standard Output Schema

The final cleaned variant tables (`.tsv`, `.xlsx`, `.pq` / `.parquet`) produced by `filter_variants.py` contain the following ordered columns:

### A. Core Variant & Genomic Coordinates
- `Locus`: Standard GRCh38 genomic coordinate (`chr:pos:ref:alt`).
- `SYMBOL`: HGNC gene symbol (e.g. `BAG3`, `MYBPC3`).
- `HGVSc`: Standard cDNA HGVS notation (e.g. `c.526C>T`).
- `HGVSp`: Standard protein HGVS notation (e.g. `p.Arg176Cys`).
- `CDNA_NAME`: Full transcript and cDNA identifier (e.g. `ENST00000343260:c.526C>T`).
- `intron_offset_signed`: **Signed** integer distance to nearest exon boundary (`-12` = 12bp intronic, `+5` = 5bp exonic).
- `splice_side`: Nearest splice site type (`donor`, `acceptor`, `exonic`).
- `IMPACT`: Original Ensembl VEP impact (`HIGH`, `MODERATE`, `LOW`, `MODIFIER`).
- `NEW_IMPACT`: Refactored unified impact incorporating splicing predictors and functional scores.

### B. Population & Functional Scores
- `AF_joint` (or `--freq-col`): Joint population allele frequency from gnomAD v4.1.
- `spliceAI_MAX`: Maximum delta score from SpliceAI (0.0 to 1.0).
- `pLI_gene_value`: gnomAD loss-of-function intolerance score.

### C. SPiP Splicing Predictor (v2.1)
- `SPiP_interpretation`: Categorical risk classification (`High`, `Moderate`, `Low`, `No impact`).
- `SPiP_prediction`: Continuous percentage probability (0.0% to 100.0%).
- `SPiP_mechanism`: Decoded splicing alteration mechanism.
- `SPiP_status`: Status contract (`scored`, `not_covered`, `error`).

### D. SpliceVault Empirical RNA Evidence
- `SpliceVault_top_events`: Raw top aberrant RNA events from GTEx/SRA data.
- `SpliceVault_Predictions_Decoded`: Human-readable decoded RNA event descriptions.
- `SpliceVault_site_sample_count`: Number of RNA-seq samples with observed aberrant splicing.
- `SpliceVault_site_max_depth`: Maximum read depth covering the aberrant site.
- `SpliceVault_out_of_frame_events`: Logical flag indicating frame-shifting events.
- `SpliceVault_site_pos`: Genomic position of empirical splice site.
- `SpliceVault_site_type`: Empirical event classification (`exon_skipping`, `cryptic_donor`, `cryptic_acceptor`).
- `SpliceVault_SpliceAI_delta`: Delta score between empirical RNA event and SpliceAI.
- `SpliceVault_status`: Status contract (`aberrant_event_detected`, `no_events_found`, `not_covered`).

### E. Pangolin Deep Learning Splicing Predictor
- `Pangolin_max_score`: Max delta score across predicted splice gain/loss positions (`-d 10000`).
- `Pangolin_heart_lv_score`: Left Ventricle specific prediction.
- `Pangolin_heart_aa_score`: Atrial Appendage specific prediction.
- `Pangolin_status`: Status contract (`scored`, `not_covered`, `error`).

### F. Branch Point Predictor Pair (Branchpointer + LaBranchoR)
- `Branchpointer_prob`: Probability of functional branch point.
- `Branchpointer_U2_energy`: Predicted U2 snRNA duplex free energy (kcal/mol).
- `Branchpoint_disrupted`: Flag indicating branchpoint motif disruption (`YES` / `NO`).
- `Branchpoint_status`: Status contract (`scored`, `not_covered`, `error`).
- `LaBranchoR_score`: Deep learning LSTM predicted branchpoint probability (0.0 to 1.0).
- `LaBranchoR_acc_dist`: Distance in bp to 3' splice site acceptor.
- `LaBranchoR_status`: Status contract (`scored`, `not_covered`, `error`).

### F2. MaxEntScan (VEP plugin)
- `MaxEntScan_ref`: Raw VEP-computed splice site strength score for the reference allele.
- `MaxEntScan_alt`: Raw VEP-computed splice site strength score for the alternate allele.
- `MaxEntScan_diff`: Raw VEP-computed ref/alt difference (VEP's own convention; kept as-is for reference).
- `MaxEntScan_pct_decrease`: `(ref - alt) / ref`, computed in-pipeline. Only defined when `MaxEntScan_ref > 0`; negative values mean the alt allele's score is *higher* than ref (splice site strengthened/cryptic site created, not flagged by `MaxEntScan_disrupted`).
- `MaxEntScan_disrupted`: `YES` if `MaxEntScan_pct_decrease >= 0.15` (a ≥15% relative decrease from ref to alt), else `NO`.
- `MaxEntScan_status`: Status contract (`scored`, or `not_covered` if ref/alt are unavailable *or* `MaxEntScan_ref <= 0` — a non-positive reference score is a normal outcome, not a predictor failure, so it is never tagged `error`).
- **Not yet used in `NEW_IMPACT`/`PRIORITY_TIER`/ACMG evidence** — informational only, by explicit decision (unlike Pangolin/SpliceAI/SPiP/SpliceVarDB, which do feed those). See [walkthrough/20260910_predictor_inventory_and_audit.md](../walkthrough/20260910_predictor_inventory_and_audit.md) (PRED-11) for rationale and status.

### G. Priority & Provenance Metadata
- `5UTR_annotation`: UTR5 regulatory annotation (if applicable).
- `5UTR_consequence`: UTR5 specific consequence term.
- `gene_priority`: Priority category of target gene (`cardiac_primary`, `secondary`, etc.).
- `SOURCE`: Pipeline stage / tool source.
- `EVIDENCE`: Aggregated supporting evidence rationale.
